# 운영 인수인계 — 하나회원권거래소 홈페이지 관리자

대상: 하나회원권거래소 시세 담당(정인철 실장) · 세느루 운영 담당

## 매주 월요일 (10분) — 시세 업로드

1. `/admin` 로그인 → **시세 관리**.
2. "현재 시세로 채운 양식 다운로드" → 엑셀에서 금일시세·전일시세 수정(동아회원권 참고해 작성하던 기존 방식 그대로).
   - 시트: 골프회원권 · 법인회원권 · 콘도회원권 · 피트니스회원권 (시트를 나눠도, 한 시트에 "구분" 열을 두어도 인식)
   - 열: 회원권명 · 금일시세(만원) · 전일시세 · 회원수 · 지역 · 비고
   - 새 종목은 행만 추가하면 자동 등록. 종목명이 바뀌면 옛 종목은 삭제.
3. 파일을 업로드 영역에 끌어놓기 → 미리보기에서 행 수·오류 확인 → **이대로 반영**.
4. 홈 상단 시세 하이라이트·시세표·골프장 페이지·llms.txt가 즉시 갱신되고, 그날 첫 자동발행 슬롯에서 주간 시세 리포트가 발행됩니다.

## 매일 — 문의 확인

- 관리자 좌측 **문의** 메뉴에 빨간 숫자가 미처리 건수. 상태(신규→연락함→완료)와 메모를 남기면 주간 리포트에 집계됩니다.
- 문의 접수 시 이메일 알림은 별도 설정 없음. 필요하면 세느루에 요청(SMTP 연동 가능).

## 콘텐츠 — 자동발행 확인 (주 1회)

- **콘텐츠(블로그)** 메뉴에서 발행된 글 제목을 훑어보고, 사실과 다른 내용이 있으면 "편집" 또는 "내리기".
- 자동발행을 "초안으로 저장"으로 바꾸면(설정 → 자동발행) 검토 후 발행하는 방식으로 운영할 수 있습니다.
- **골프장 소개** 메뉴: 기본 정보(홀수·주소)는 공개 자료 기반 초기값이므로 **확인 후 "검증" 체크** → 검증된 골프장만 홀수가 공개 표시됩니다. 틀린 정보는 "편집"에서 수정.
- 유튜브 영상은 **공지·뉴스·유튜브** 메뉴에서 URL과 제목만 넣으면 홈·유튜브 페이지에 VideoObject 스키마로 노출됩니다. 채널 최신 영상 5~10개를 먼저 넣어 두세요.

## 매물

- **매물** 메뉴에서 등록. "홈 추천 노출"을 켜면 홈 화면에 카드로 표시. 종류에 "무기명" / "대명" / "선불카드"를 쓰면 해당 전용관에 자동 분류됩니다.

## 리포트 (전후 스크린샷 자동 첨부)

- 리포트 0번 섹션에 **전후 비교 이미지**가 자동으로 들어갑니다. 좌: 기존 hanamarket.co.kr(2026-09-15 기준 캡처, 저장소 `data/seed/screenshots/before`), 우: 신규 홈페이지 최신 캡처(홈·시세표·골프장 안내·회사소개 + 관리자 4화면).
- 매주 월요일 리포트 생성 직전 서버가 자동 캡처합니다(Railway에 chromium 포함 빌드). 수동 캡처는 관리자 → 리포트 → 「지금 캡처」, 서버에 크롬이 없으면 로컬에서 `node scripts/capture.js after https://배포주소` 실행 후 「이미지 업로드」.
- 원본 PNG(데스크톱 1440×900·모바일·전체 페이지)와 좌우 합성본은 `Desktop\하나회원권 홈페이지\측정\스크린샷\<날짜>\`에 보관합니다.

- 매주 월요일 08:30 자동 생성 → **리포트** 메뉴에서 HTML 열기(인쇄 → PDF 저장) 또는 DOCX 다운로드.
- 4주차가 끝나면 월간 종합 리포트가 추가됩니다. 클라이언트 전달용은 DOCX.

## 비밀번호·보안

- 첫 로그인 후 **설정 → 관리자 비밀번호 변경** 필수.
- API 키(LLM·인블로그)는 설정 화면에서 마스킹되어 표시되며 서버 DB에만 저장됩니다.

## 문제가 생기면

| 증상 | 확인 |
|---|---|
| 자동발행이 안 됨 | 자동발행 메뉴 → 최근 실행에 failed 사유. LLM 키 없음이면 가이드·동향 글은 생성 불가(시세 리포트·골프장 소개만 발행) |
| 인블로그 오류 | 콘텐츠 목록 "오류" 마우스오버로 사유 확인 → 대부분 플랜(Team 이상)·키 만료. 연결 테스트로 재확인 |
| 시세 업로드 오류 | 미리보기의 경고 문구(행 번호·종목) 확인 → 숫자 아닌 값·빈 종목명 수정 |
| 사이트가 옛 버전으로 보임 | Ctrl+F5. 정적 파일은 배포 시각 도장이 붙어 자동 갱신 |


## 동아회원권 시세 자동 반영 (2026-09-29 추가)

- 매일 08:30(KST, 관리자 설정 `donga_time`으로 변경) 동아회원권거래소 골프회원권 시세 페이지(https://www.dongagolf.co.kr/membership/golf)를 읽어, 종목명이 매핑된 우리 골프 종목의 금일시세로 반영하고 이력을 남긴다. 켜고 끄기는 설정 `donga_sync`(기본 켜짐).
- 매핑: 이름 정규화 자동 매칭 + 기본 매핑(lib/donga.js `DEFAULT_MAP`) + 관리자 수동 매핑(자동발행 화면 → 동아 시세 카드 → 수동 매핑 JSON). 매핑되지 않은 종목은 값이 바뀌지 않는다(2026-09-29 기준 미매핑 5: 레이크우드 분담금·블루원보문·인터불고경산 25000/27000·캐슬렉스제주 우대 → 정인철 실장 확인 필요).
- 월요일 엑셀 업로드는 그대로 유효하다. 같은 날 두 번 반영되면 나중 값이 남는다(엑셀이 08:30 이후면 엑셀 값).
- 출처 표시는 관리자 화면에만 한다. 공개 페이지·리포트에는 "실거래·호가 기준"으로만 표기한다. 타사 시세를 그대로 재게시하는 것이므로 클라이언트가 이 방식을 승인했는지 확인해 두는 것이 안전하다.
- 동아 페이지 구조(표 헤더 "회원권명/금일시세/전일시세")가 바뀌면 파싱이 0건이 되고 관리자 카드에 실패로 표시된다. 그때는 lib/donga.js `parse()`를 고친다.
