# 인블로그(inblog) 세팅 가이드 — 하나회원권거래소

홈페이지가 매일 2건 발행하는 글을 인블로그 블로그에도 자동으로 올리고, 인블로그 글이 홈페이지를 "원문"으로 가리키게(canonical) 만드는 절차입니다. 계정 생성·결제·API 키 발급은 **하나회원권 담당자 또는 세느루 담당자가 직접** 진행합니다(비밀번호·결제정보는 대행 불가).

## 0. 준비물

| 항목 | 값 |
|---|---|
| 블로그 주소(서브도메인) | `blog.hanamarket.co.kr` (권장. 새 도메인을 쓰면 그 도메인의 `blog.`) |
| 도메인 DNS 관리 권한 | 가비아·후이즈 등 hanamarket.co.kr 등록업체 로그인 |
| 인블로그 플랜 | **Team 플랜 이상** — API가 유료 플랜에서만 동작(무료 전환 시 API 키 정지). 14일 체험 기간에도 API 사용 가능 |
| 홈페이지 관리자 | `/admin` → 설정 → 인블로그 API 키 · 인블로그 주소 |

## 1. 계정·블로그 생성 (10분)

1. https://inblog.ai 회원가입 → 블로그 만들기.
2. 블로그 이름: `하나회원권거래소 시세 리포트·가이드` / 설명: `골프·콘도·피트니스 회원권 시세 리포트와 거래 가이드. 2004년부터 회원권 매매를 중개해 온 하나회원권거래소가 발행합니다.` / 언어 ko / 로고·파비콘·OG: `public/img/logo.png`, `icon-512.png`, `og.png` 업로드.
3. 저자 프로필: `하나회원권거래소 편집팀` (아바타 `mark.png`). 저자 소개에 회사 한 줄 + 홈페이지 링크.
4. 대시보드 → 설정 → 요금제에서 Team 플랜 결제(담당자 직접).

## 2. 커스텀 도메인 연결 (DNS 전파 최대 24시간)

1. 대시보드 → 설정 → **커스텀 도메인** → "서브도메인" 선택 → `blog.` 뒤에 `hanamarket.co.kr` 입력 → 연결 시작하기.
2. 화면에 표시되는 DNS 레코드(CNAME 등)를 **그대로** 도메인 등록업체 DNS에 추가. (값은 계정마다 대시보드에서 발급되므로 이 문서에 적지 않음 — 화면 값을 복사)
3. Cloudflare 프록시를 쓰는 도메인이면 해당 레코드는 안내에 따라 설정. Cafe24·아임웹 DNS도 CNAME 추가는 가능.
4. `inblog blogs domain status` 또는 대시보드에서 "연결 완료" 확인 → SSL 자동 발급.
5. CLI로도 가능: `npm i -g @inblog/cli` → `inblog auth login --api-key` → `inblog blogs domain connect blog.hanamarket.co.kr`.

## 3. API 키 발급 → 홈페이지 연결 (5분)

1. 대시보드 → 설정 → **API 키** → 새 키 발급(이름: `hanamarket-site`). 키는 한 번만 표시되므로 복사.
2. 홈페이지 `/admin` → 설정 → **인블로그 API 키**에 붙여넣기, **인블로그 주소**에 `https://blog.hanamarket.co.kr` 입력, 자동 전송 ON → 저장.
   - 또는 Railway 환경변수 `INBLOG_API_KEY`로 설정(환경변수가 우선).
3. `/admin` → 자동발행 → **연결 테스트** 클릭 → 블로그 이름·플랜이 뜨면 성공.
4. 콘텐츠 메뉴에서 기존 글 하나를 골라 **인블로그 전송** → 인블로그 대시보드에 글이 나타나는지 확인. 이후 자동발행 글은 발행과 동시에 전송됩니다.

전송 규칙: 제목·본문·meta description·FAQ JSON-LD를 함께 보내고, `canonical_url`을 홈페이지 원문(`/blog/slug`)으로 지정합니다. 홈페이지 글을 초안으로 내리면 인블로그에서도 비공개 처리됩니다. 전송 실패는 콘텐츠 목록에 "오류"로 표시되며 재전송 버튼으로 다시 보냅니다.

## 4. 검색엔진 등록

1. **구글 서치콘솔**: URL 접두어 `https://blog.hanamarket.co.kr` → HTML 태그 방식 → 태그 값을 인블로그 대시보드 SEO 설정에 붙여넣기 → 확인(전파 지연으로 3~4회 재시도 필요할 수 있음) → 사이트맵 `sitemap.xml` 제출.
2. **네이버 서치어드바이저**: 같은 방식으로 소유확인 메타태그 등록 → 사이트맵 제출 → "수집 요청"으로 첫 10개 글 요청.
3. 홈페이지 쪽도 동일하게: `/admin` → 설정 → 네이버·구글 소유확인 값 입력 → 서치콘솔/서치어드바이저에 `https://www.hanamarket.co.kr/sitemap.xml` 제출.

## 5. 상호 연결(sameAs)

- 홈페이지 설정에 인블로그 주소를 넣으면 Organization 스키마 `sameAs`·푸터·블로그 목록에 자동 반영됩니다.
- 인블로그 블로그 설정의 "홈페이지 링크"와 저자 소개에 `https://www.hanamarket.co.kr`을 넣어 양방향으로 연결합니다.
- 인블로그 글 하단 CTA: 기본으로 `회원권 매매 상담 신청 → /apply`가 전송됩니다.

## 6. 발행 후 점검(주 1회)

- 인블로그 대시보드 → 콘텐츠 성과: 노출·클릭 상위 글 확인.
- 홈페이지 `/admin` → 기술 감사·방문: AI 크롤러(OAI-SearchBot·PerplexityBot·Claude-User) 방문 수 추이.
- 주간 리포트에 인블로그 동기화 건수와 오류 건수가 자동 집계됩니다.
