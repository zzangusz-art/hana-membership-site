# 검색엔진 등록 가이드 — 구글 서치콘솔 · 네이버 서치어드바이저 · 수집 요청

작성 2026-09-22 (2주차). 정식 도메인이 연결된 뒤 진행한다. 아래 `https://hanamember.co.kr`는 예시이며 확정 도메인으로 바꿔 읽는다. 임시 도메인(`*.up.railway.app`)은 앱이 자동으로 noindex 헤더를 내보내므로 등록하지 않는다.

## 0. 사전 확인 (5분)

| 확인 | 방법 | 기대값 |
|---|---|---|
| SITE_URL | Railway 변수 `SITE_URL` 또는 관리자 → 설정 → 사이트 URL | 확정 도메인(https, www 여부 포함) |
| HTTPS | 브라우저에서 도메인 접속 | 자물쇠, 인증서 오류 없음 |
| noindex 해제 | `curl -sI https://도메인/ \| grep -i x-robots` | 아무 것도 안 나와야 함 |
| robots | `https://도메인/robots.txt` | `Sitemap: https://도메인/sitemap.xml` 포함, AI 봇 Allow |
| 사이트맵 | `https://도메인/sitemap.xml` | 홈·시세·골프장·글 URL 전부 확정 도메인으로 시작 |

## 1. 구글 서치콘솔 (Google Search Console)

계정: 세느루 구글 계정으로 등록하고 하나회원권 담당자(정인철)를 "소유자"로 추가한다. 계정 로그인·인증 코드 입력은 재현이 직접 한다.

1. https://search.google.com/search-console → 속성 추가.
2. 속성 유형 선택
   - **URL 접두어**(권장, 코드 수정 없음): `https://hanamember.co.kr/` 입력 → 확인 방법 "HTML 태그" → `content="..."` 값만 복사.
   - 도메인 속성(DNS TXT): 도메인 DNS에 TXT 추가 가능할 때만. www/비www·http/https를 한 번에 잡는 장점.
3. HTML 태그 값을 **관리자 → 설정 → Google 사이트 확인 코드**에 붙여넣고 저장 (모든 페이지 `<head>`에 `google-site-verification` 메타가 자동 출력됨). 또는 Railway 변수 `GOOGLE_SITE_VERIFICATION`.
4. 서치콘솔에서 "확인" 클릭.
5. 색인 → Sitemaps → `sitemap.xml` 제출. (RSS도 받아주므로 `rss.xml`을 추가로 제출해도 됨.)
6. URL 검사 도구로 홈·시세표·골프장 목록 3개를 "색인 생성 요청".
7. 설정 → 사용자 및 권한 → 하나회원권 담당자 이메일을 소유자로 추가.

확인 후 1~2주 뒤 볼 것: "페이지" 보고서에서 색인된 페이지 수, "실적"에서 브랜드 검색어 노출. 리치 결과(FAQ·조직·빵부스러기)는 "개선사항"에 나타난다.

## 2. 네이버 서치어드바이저 (Naver Search Advisor)

1. https://searchadvisor.naver.com → 웹마스터 도구 → 사이트 등록 → `https://hanamember.co.kr` 입력.
2. 소유 확인 → "HTML 태그" → `content="..."` 값 복사.
3. **관리자 → 설정 → 네이버 사이트 확인 코드**에 저장 (또는 Railway 변수 `NAVER_SITE_VERIFICATION`) → 서치어드바이저에서 소유 확인.
4. 검증 → robots.txt 검증 (Allow 확인), 사이트맵 검증.
5. 요청 → 사이트맵 제출: `https://hanamember.co.kr/sitemap.xml`
6. 요청 → RSS 제출: `https://hanamember.co.kr/rss.xml`
7. 요청 → **웹 페이지 수집** — 아래 20개 URL을 하루 안에 나눠 요청한다(일일 한도 있음, 보통 50건).
8. 설정 → 사이트 간단 체크로 title·description·OG 정상 여부 확인.

## 2-1. IndexNow (네이버·Bing 즉시 색인, 자동)

앱에 내장되어 있어 따로 할 일이 없다. 글이 발행될 때마다 `api.indexnow.org`로 URL을 보내고, 네이버(2023-07-25부터 지원)·Bing이 이를 받아 크롤 대기 없이 색인한다. 키는 관리자 → 자동발행 → "색인 요청" 카드에 있고, `https://도메인/<키>.txt`로 노출된다.

- 임시 도메인(`*.railway.app`)에서는 전송하지 않는다(noindex). **정식 도메인 연결 후 관리자에서 "사이트맵 전체 제출"을 1회 누른다.**
- 서치어드바이저에 사이트를 등록해 두면 "요청 → IndexNow" 메뉴에서 수신 이력을 볼 수 있다.
- 구글은 IndexNow를 받지 않으므로 1번의 사이트맵 제출이 그대로 필요하다.

## 3. Bing 웹마스터 도구 (선택, 5분)

https://www.bing.com/webmasters → "Google Search Console에서 가져오기"로 1번 속성을 그대로 가져오면 끝. ChatGPT 검색(Bing 색인 기반)에 노출되려면 필요하다.

## 4. 등록 후 앱 쪽 확인

- 관리자 → 감사(자체 기술 감사) 100점 유지.
- `https://도메인/llms.txt`, `/llms-full.txt` 접근 확인(AI 검색용).
- 구 도메인 hanamark.co.kr 301이 끝난 뒤(문서 `구도메인-301-요청문.md`) 서치콘솔에 구 도메인 속성도 추가해 "주소 변경" 도구로 이전을 알린다(구 도메인 소유 확인이 가능할 때).
