# 구 도메인 hanamark.co.kr → 신규 사이트 301 리다이렉트

작성 2026-09-22. 배경: 9/15 Perplexity 실측에서 브랜드 질의에 **구 도메인 hanamark.co.kr가 1순위로 인용**됨. 구 도메인이 계속 살아 있으면 AI 검색·구글이 옛 페이지를 정답으로 유지하므로, 전체 URL을 신규 사이트로 301 해야 신뢰도가 이전된다.

## 방법 A (권장) — DNS만 바꾸고 앱이 301 처리

앱(server.js)에 별칭 호스트 처리를 넣어 두었다. `hanamark.co.kr`, `www.hanamark.co.kr`로 들어온 모든 요청은 **경로를 유지한 채** `SITE_URL`로 301 되고, 이어서 구 URL 27개(`/market/01/` 등)는 신규 경로로 한 번 더 301 된다(최대 2단계, 검색엔진 허용 범위).

재현이 할 일:
1. Railway → 서비스 → Settings → Networking → Custom Domain에 `hanamark.co.kr`과 `www.hanamark.co.kr` 추가. Railway가 알려주는 CNAME 값을 받는다.
2. 구 도메인 DNS(등록 업체 관리 화면)에서 `www` CNAME을 Railway 값으로, 루트(`@`)는 ALIAS/ANAME 또는 A 레코드로 Railway 안내대로 변경. (루트 도메인에 CNAME을 못 거는 업체면 `www`만 걸고 루트는 업체의 "URL 포워딩"으로 `https://www.hanamark.co.kr`를 가리킨다.)
3. 전파 후 확인:
   ```
   curl -sI https://www.hanamark.co.kr/market/01/ | grep -i "HTTP\|location"
   ```
   기대: `301` + `location: https://<신규도메인>/market/01/` → 다시 `301` → `/market/golf`.
4. 다른 별칭이 더 있으면 Railway 변수 `REDIRECT_HOSTS=hanamark.co.kr,www.hanamark.co.kr,다른도메인` 으로 추가.

주의: 이 방법은 구 홈페이지 서버를 내리는 것과 같다. 구 홈페이지 콘텐츠 중 옮길 것(공지·뉴스)은 2주차 "기존 홈페이지 공지·뉴스 이관 검수" 항목에서 먼저 끝낸다.

## 방법 B — 호스팅 업체에 리다이렉트 요청 (DNS를 못 만질 때)

아래 문구를 구 홈페이지 호스팅·제작 업체에 보낸다.

---

제목: hanamark.co.kr 전체 페이지 301 리다이렉트 설정 요청

안녕하세요, (주)하나회원권거래소입니다.
홈페이지를 새 주소로 이전하여 기존 도메인 hanamark.co.kr(및 www.hanamark.co.kr)로 들어오는 **모든 요청**을 아래와 같이 301(영구 이동)으로 보내 주시기 바랍니다.

- 규칙: `https://hanamark.co.kr/<경로>` 및 `https://www.hanamark.co.kr/<경로>` → `https://www.hanamarket.co.kr/<경로>` (경로·쿼리 그대로 유지)
- 상태 코드: 301 (302·메타 리프레시·자바스크립트 이동 아님)
- HTTP·HTTPS 모두 적용, 인증서는 만료 전까지 유지
- 기존 페이지는 리다이렉트 이후 삭제하셔도 됩니다.

Apache 예시 (.htaccess):
```
RewriteEngine On
RewriteCond %{HTTP_HOST} ^(www\.)?hanamark\.co\.kr$ [NC]
RewriteRule ^(.*)$ https://www.hanamarket.co.kr/$1 [R=301,L]
```
Nginx 예시:
```
server { server_name hanamark.co.kr www.hanamark.co.kr; return 301 https://www.hanamarket.co.kr$request_uri; }
```

설정 완료 후 회신 주시면 저희가 확인하겠습니다. 감사합니다.
