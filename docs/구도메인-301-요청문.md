# 구 도메인 hanamarket.co.kr → 신규 사이트 301 리다이렉트

작성 2026-09-22. 배경: 9/15 Perplexity 실측에서 브랜드 질의에 **구 도메인 hanamarket.co.kr가 1순위로 인용**됨. 구 도메인이 계속 살아 있으면 AI 검색·구글이 옛 페이지를 정답으로 유지하므로, 전체 URL을 신규 사이트로 301 해야 신뢰도가 이전된다.


## 2026-11-13 현재 상태 (먼저 읽기)

- 구 도메인 표기 정정: 이 문서의 옛 표기 hanamark.co.kr은 **hanamarket.co.kr**의 오기입니다.
- 구 사이트: nginx/PHP 서버(183.111.174.66), 네임서버 ns1~3.hanamarket.co.kr(호스팅 업체 관리).
- **메일**: MX가 rmw-002.fmcity.com 입니다. @hanamarket.co.kr 메일을 쓰고 있으면 DNS를 옮기거나 바꿀 때 MX 레코드를 그대로 유지해야 메일이 끊기지 않습니다.
- 새 사이트(앱) 준비 완료(로컬 검증): hanamarket.co.kr·www로 들어온 요청은 경로를 유지해 https://hanamember.co.kr 로 301, 이어서 구 주소 → 새 주소로 301.
  - 메뉴 주소(/market/01 등 27개), 골프장 상세(/golf/01_view/번호), **매물·전용관 상세(/membership/04_view/62 → /listings/해당 매물)**, 게시판 상세(목록으로), /index.php(홈)
- 구 사이트를 내리면 **법인·콘도·피트니스 시세 입력처가 사라집니다**(지금은 구 사이트에 입력된 값을 받아 반영). 전환 전에 업체가 새 관리자 「시세 관리」(엑셀 업로드·수기 수정)로 입력하도록 바꿔야 합니다.

### 방법 C (가장 단순) — 구 도메인을 Cloudflare로 옮기고 규칙 1개
1. 구 도메인 DNS 레코드(특히 MX·메일 관련 TXT)를 Cloudflare에 그대로 옮겨 적는다.
2. 도메인 등록 업체에서 네임서버를 Cloudflare 값으로 변경.
3. Cloudflare 리디렉션 규칙: `hanamarket.co.kr/*`·`www.hanamarket.co.kr/*` → `https://hanamember.co.kr/${1}` (301, 쿼리 유지). 이후 경로 매핑은 새 사이트 앱이 처리.

## 방법 A (권장) — DNS만 바꾸고 앱이 301 처리

앱(server.js)에 별칭 호스트 처리를 넣어 두었다. `hanamarket.co.kr`, `www.hanamarket.co.kr`로 들어온 모든 요청은 **경로를 유지한 채** `SITE_URL`로 301 되고, 이어서 구 URL 27개(`/market/01/` 등)는 신규 경로로 한 번 더 301 된다(최대 2단계, 검색엔진 허용 범위).

재현이 할 일:
1. Railway → 서비스 → Settings → Networking → Custom Domain에 `hanamarket.co.kr`과 `www.hanamarket.co.kr` 추가. Railway가 알려주는 CNAME 값을 받는다.
2. 구 도메인 DNS(등록 업체 관리 화면)에서 `www` CNAME을 Railway 값으로, 루트(`@`)는 ALIAS/ANAME 또는 A 레코드로 Railway 안내대로 변경. (루트 도메인에 CNAME을 못 거는 업체면 `www`만 걸고 루트는 업체의 "URL 포워딩"으로 `https://www.hanamarket.co.kr`를 가리킨다.)
3. 전파 후 확인:
   ```
   curl -sI https://www.hanamarket.co.kr/market/01/ | grep -i "HTTP\|location"
   ```
   기대: `301` + `location: https://<신규도메인>/market/01/` → 다시 `301` → `/market/golf`.
4. 다른 별칭이 더 있으면 Railway 변수 `REDIRECT_HOSTS=hanamarket.co.kr,www.hanamarket.co.kr,다른도메인` 으로 추가.

주의: 이 방법은 구 홈페이지 서버를 내리는 것과 같다. 구 홈페이지 콘텐츠 중 옮길 것(공지·뉴스)은 2주차 "기존 홈페이지 공지·뉴스 이관 검수" 항목에서 먼저 끝낸다.

홈페이지를 새 주소로 이전하여 기존 도메인 hanamarket.co.kr(및 www.hanamarket.co.kr)로 들어오는 **모든 요청**을 아래와 같이 301(영구 이동)으로 보내 주시기 바랍니다.

- 규칙: `https://hanamarket.co.kr/<경로>` 및 `https://www.hanamarket.co.kr/<경로>` → `https://hanamember.co.kr/<경로>` (경로·쿼리 그대로 유지)
- 상태 코드: 301 (302·메타 리프레시·자바스크립트 이동 아님)
- HTTP·HTTPS 모두 적용, 인증서는 만료 전까지 유지
- 기존 페이지는 리다이렉트 이후 삭제하셔도 됩니다.

Apache 예시 (.htaccess):
```
RewriteEngine On
RewriteCond %{HTTP_HOST} ^(www\.)?hanamark\.co\.kr$ [NC]
RewriteRule ^(.*)$ https://hanamember.co.kr/$1 [R=301,L]
```
Nginx 예시:
```
server { server_name hanamarket.co.kr www.hanamarket.co.kr; return 301 https://hanamember.co.kr$request_uri; }
```

설정 완료 후 회신 주시면 저희가 확인하겠습니다. 감사합니다.
